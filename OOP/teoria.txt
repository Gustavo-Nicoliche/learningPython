Sistemas Orientados a Objetos:

Confiabilidade:
- O isolamento entre as partes gera algo mais seguro. Ao alterar uma das partes,
nenhuma outra é afetada.

Oportunidade:
- Ao dividir tudo em partes, cada uma delas pode ser desenvolvida em paralelo.

Manutenibilidade:
- Atualizar é mais fácil. Uma pequena alteração vai beneficiar todas as partes
relacionadas.

Extensibilidade:
- Um sistema não deve ser estático, tudo deve mudar e crescer para permanecer útil.

Reusabilidade:
- Objetos que foram criados para um sistema podem ser aproveitados em outros Sistemas.

Naturalidade:
- Mais fácil de entender. Maior atenção às funcionalidades do que aos detalhes de
implementação.

Classe: simbolizam "formas"(de formato) para ciração de objetos.  
- Determina-se em uma classe: nome, características próprias, coisas que pode fazer.
-exemplo: 
    nome - Biscoito.

        + tamanho

        + temperatura
    # métodos:
        + cozinhar()

        + cobrir()
        + confeitar()
        + podeCOmer()

Instância: Seguir o padrâo que foi definido na classe para criar um objeto.
Instanciar um a classe.
- O objeto é a instância de uma classe. Pode-se ter mais de um objeto do mesmo tipo.

Objeto: " Coisa material ou abstrata que é feita a partir de uma classe e pode ser
descrita por meio das suas características (atributos), comportamentos (métodos) e
estado atual "

-exemplo: 
    nome - Biscoito.
    # características:
        + tamanho = 8cm
        + massa = baunilha
        + peso = 54g
        + cobertura = pistache
        + cozido = True
        + temperatura = 55°C

Os valores das características tamanho, massa, peso, etc, compõem o ESTADO do objeto.
